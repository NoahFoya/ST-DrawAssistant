# ST-DrawAssistant 绘画助手

ST-DrawAssistant 是一款运行于 SillyTavern（酒馆）网页前端的 AI 绘画调度与交互扩展插件。支持在角色对话中解析生图标记并就地出图，对接多种本地与云端生图后端，并提供提示词工程辅助、素材档案库、运行统计与画廊检视。

---

## 运行前提与架构说明

> **重要说明**：ST-DrawAssistant 属于轻量客户端扩展，**插件本身不包含任何生图模型、权重文件或计算引擎**。实际出图依托于在外部独立运行的生图后端（如本地部署的 ComfyUI / SD-WebUI，或云端 NovelAI 等）。在使用本插件前，请确保对应的生图服务已正常启动并开放了网络访问。

### 推荐通信架构：浏览器直连 (Direct)
插件默认采用**浏览器直连模式**：浏览器直接向生图后端发送 HTTP 请求，具备响应直接、无需经过酒馆服务端转发的优点。

为了让浏览器能够正常访问本地运行的生图服务，需要在生图后端的启动配置中允许跨域访问（CORS）：

- **ComfyUI 启动参数**：
  在启动脚本（如 `run_nvidia_gpu.bat`）的启动命令中添加：
  ```bash
  --listen 127.0.0.1 --enable-cors-header *
  ```
  *(如需同一局域网内其他设备访问，可将 `127.0.0.1` 替换为 `0.0.0.0`)*

- **Stable Diffusion WebUI / Forge 启动参数**：
  在 `webui-user.bat` 的 `set COMMANDLINE_ARGS=` 中追加：
  ```bash
  --api --cors-allow-origins=*
  ```

### 关于酒馆代理模式 (Proxy) 的使用前提
若你的 SillyTavern 部署在远程 HTTPS 域名下，而生图服务运行在本地无 SSL 证书的 HTTP 环境中，浏览器安全策略（Mixed Content）会阻止前端直连。
此时可在常规设置中切换为「酒馆代理」模式，由酒馆服务端负责中转 HTTP 请求。请注意：
- **需开启酒馆 CORS 代理配置**：须确保酒馆配置文件 `config.yaml` 中已开启 `enableCorsProxy: true`；
- **适合作为 HTTPS 混合内容或 CORS 受限时的兼容模式**：只要网络与证书条件允许，建议优先使用浏览器直连模式以获得更低的请求延迟。

## 主要功能

### 1. 对话楼层内嵌交互
- **生图指令解析与就地渲染**：当 AI 角色在回复中输出生图指令标记（默认 `<image>image###正向提示词|负向提示词###</image>`，支持在常规设置中自定义起止标记）时，插件会自动解析并在该条消息底部就地呈现出图控制卡片，不破坏原有对话排版。
- **状态流转与即时重试**：出图按钮根据后台执行状态平滑流转（「点击生图」➔「排队中」➔「生成中」➔「重新生成」）。出图后支持点击大图进入全屏检视（支持触控缩放与轻扫切图），或右键/长按唤起图像操作面板。
- **提示词检查与辅助重绘**：在图像操作面板中可查看该图片的生成参数，基于原始生图提示词微调正向与负向提示词重新出图（不会重复叠加预设前后缀），亦可在支持重绘的后端下通过辅助画板涂抹选区进行局部重绘 (Inpaint)。

### 2. 生图后端适配
- **ComfyUI**：
  - 支持标准 API 格式工作流解析，通过 `POST /prompt` 提交任务并轮询 `/history/{prompt_id}` 获取生成结果，详细解析服务端 `node_errors` 节点报错；任务取消或超时采用客户端抛弃策略（仅中止本地等待，不向服务端发送队列删除或中断指令）；
  - **工作流格式要求**：必须在 ComfyUI 网页设置中开启「Enable Dev mode Options」，并通过**「Save (API Format)」**导出 JSON 文件（常规保存的带界面 JSON 无法被后台执行接口识别）；
  - **动态 LoRA 与内置工作流依赖**：内置 WeiLin 默认工作流依赖 `WeiLinPromptUI` 节点插件解析 `<wlr:name:weight>` 动态 LoRA 语法，其中内置重绘工作流已接入 `%inpaint_mask%` 蒙版通道；若使用自定义原生节点工作流，可在提示词设置中按需调整 LoRA 语法模式。
- **Stable Diffusion WebUI / Forge**：
  - 支持文生图 (`txt2img`) 与局部重绘 (`img2img`) 接口，自动采纳重绘画板实际宽高并适配 `Automatic` VAE；
  - 支持高分辨率修复 (Hires.fix) 与采样器/调度器自动同步及 `<lora:name:weight>` 提示词嵌入转换；取消任务时同样仅中止本地网络等待。
- **NovelAI**：
  - 支持 V3、V4.5、V5 官方结构化提示词格式 (`v4_prompt`) 与 ZIP 响应解包，固定发送精简 `ucPreset` 策略并自动对齐分辨率；
  - 保留内置官方模型清单并支持自定义模型覆写，不向官方或自定义代理发起无效的模型列表探测。
- **OpenAI 兼容接口**：
  - 支持标准 `/v1/images/generations` 协议接口及多服务商隔离配置，内建适配官方 OpenAI（含 `gpt-image-1` 尺寸/画质映射）、SiliconFlow（自动映射 `image_size`/`batch_size`）、Gemini OpenAI 兼容及自定义兼容服务，并自动屏蔽不适用的负向提示词与局部重绘入口。

### 3. 提示词通道与素材档案
- **提示词多通道注入**：提供故事插画（默认开启）、词汇指导、素材创作与素材注入四大分类通道；底层共享同一套触发、深度与变量注入机制，既可按默认起始模板自由调整或合并，也可在挂载外部绘画世界书时按需关闭。
- **素材档案库与宏规则**：集中维护角色与服装的常驻特征、触发词及各生理/穿搭部位（如 `$Alice$`、`$Alice-head$`），在提交生图前自动就地展开为对应 Tags，避免手动重复编写。
- **提示词清洗与规范化**：自动剔除大模型思考过程标签（`<think>...</think>`）与多余标点，保留规范的权重括号并执行 Tag 级排重。

### 4. 运行统计与本地图库
- **运行效能监控**：汇总累计生成数、今日出图量、近 7 日出图走势双轨微图表（出图数量柱状 + 平均耗时折线）以及最近生成记录流水表。
- **本地存储与画廊**：生成的图片与技术参数默认保存在浏览器本地 IndexedDB 中，支持时间筛选、标星收藏与批量导出，不占用酒馆对话记录体积。

## 安装方法

通过 SillyTavern 扩展管理器安装：
1. 登录并打开 SillyTavern 网页；
2. 打开顶栏或侧边栏的 **扩展 (Extensions)** ➔ **扩展管理 (Extension Management)**；
3. 在 **从 URL 安装 (Install Extension)** 输入框中粘贴本项目的 Git 仓库链接：
   ```text
   https://github.com/NoahFoya/ST-DrawAssistant.git
   ```
4. 点击 **安装 (Install)**，安装完成后刷新网页即可开始使用。

## 快速配置流程

1. **唤出设置面板与功能引导**：点击页面右侧常驻的悬浮球图标，或使用键盘快捷键 `Ctrl + Shift + D`。首次初始化进入面板时将自动弹出分步功能引导，后续也可随时点击设置顶栏右上角的 `?` 帮助按钮重新打开。
2. **选择生图服务**：在左侧「生图后端配置」卡片中选择正在使用的引擎（如 ComfyUI 或 SD-WebUI）。
3. **填写服务地址**：
   - 本地 ComfyUI 默认地址通常为 `http://127.0.0.1:8188`；
   - 本地 SD-WebUI 默认地址通常为 `http://127.0.0.1:7860`。
4. **测试连接与资产同步**：支持模型拉取的引擎（ComfyUI / SD-WebUI / OpenAI 兼容）请点击卡片右上角「测试连接/同步模型」按钮，连通后会自动拉取模型与 LoRA 清单；NovelAI 仅提供「测试连接」按钮，直接使用内置官方模型清单或自定义模型名覆盖。
5. **配置提示词预设**：在「提示词与通道」中参照默认起始预设按需调整内容与开关（若已使用外部绘画世界书，亦可关闭内置提示词通道），完成基础设置。

## 常见排障与注意项 (FAQ)

### 1. 点击「测试连接」提示网络错误或无法连通？
- **排查一：生图后端是否已启动**：请确认本地服务终端窗口处于运行状态，在浏览器直接打开 `http://127.0.0.1:8188`（ComfyUI）或 `http://127.0.0.1:7860`（SD-WebUI）能够正常看到网页。
- **排查二：是否已添加跨域参数**：ComfyUI 必须配置 `--enable-cors-header *`，SD-WebUI 必须配置 `--cors-allow-origins=*`。若未配置，浏览器控制台会报出 CORS 跨源拦截错误。
- **排查三：SD-WebUI 是否开启了 API 接口**：SD-WebUI 启动参数必须包含 `--api`，否则其后台接口默认不开放。
- **排查四：协议混合拦截**：若酒馆使用 HTTPS 域名，浏览器无法直接请求 HTTP 接口，需将酒馆切换为本地 HTTP 运行，或在常规设置中权衡开启「酒馆代理」。

### 2. ComfyUI 提示工作流无法执行或缺少节点？
- 确认导入的 JSON 文件是通过 ComfyUI 开发者模式下的 **「Save (API Format)」** 导出的。普通「Save」导出的工作流包含大量 UI 节点，无法直接被后台执行接口识别。
- 若使用内置 WeiLin 默认工作流或提示词中包含了 `<wlr:name:weight>` 动态语法，请确保 ComfyUI 服务端已安装包含 `WeiLinPromptUI` 的节点插件。

### 3. 如何备份已配置的参数或恢复初始状态？
- **配置导出与导入**：在「关于」选项卡中的「配置备份与恢复」区域，点击「导出完整配置 (JSON)」可保存当前所有自定义预设；换设备或重装时点击「导入配置备份」即可恢复。
- **恢复出厂设置**：点击「恢复出厂设置」按钮将打开分类勾选弹窗，可针对性重置全局设置或各分类预设方案，本地收藏图库与自定义词库默认隔离保护。
