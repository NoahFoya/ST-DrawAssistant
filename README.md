# Starlight DrawAssistant (ST-DrawAssistant)

ST-DrawAssistant 是一款运行于 SillyTavern（酒馆）网页前端的 AI 绘画辅助扩展插件。支持结合角色对话上下文在消息楼层中直接出图，并对接多种本地与云端生图后端服务。

---

## 主要功能

- **对话楼层交互生图**：
  - 在角色消息楼层下方提供生图按钮，可直接根据当前楼层及上下文提示词一键生成图像；
  - 支持配置提取占位标记（如 `image###...###`），自动提取正反向提示词与参数；
  - 支持开启“AI 回复后自动生图”，满足特定场景下的连续插图生成需求；
  - 楼层图片支持原位点击展开/折叠、大图灯箱预览以及查看详细生成元数据。

- **多后端生图引擎支持**：
  - **ComfyUI**：支持基于 WebSocket 实时进度反馈、WeiLin 4 段式 LoRA 语法转换与标准 Checkpoint 工作流，支持排队任务主动中断；
  - **Stable Diffusion WebUI / Forge**：支持经典 txt2img 与 img2img 接口、`<lora:name:weight>` 提示词嵌入与任务主动中断；
  - **NovelAI**：支持 V3、V4.5、V5 专属提示词结构与分辨率约束；
  - **OpenAI 兼容接口**：支持调用 DALL-E 3、FLUX 以及其他符合 OpenAI 图像接口规范的第三方中转服务。

- **灵活的存储策略**：
  - 默认使用浏览器的 IndexedDB 进行本地持久化存储，不依赖外部服务器；
  - 可选开启“保存至酒馆服务器”（将图片上传至酒馆后端静态目录）或“内嵌至聊天记录”（转码为 Base64 随聊天记录保存）。

- **提示词流水线与标签排重**：
  - 自动过滤大模型思维链标签与多余文本；
  - 支持画质修饰词预设拼接、角色卡 LoRA 提取；
  - 内置纯函数 Tag 级排重算法，保留权重语法结构的同时消除重复提示词。

- **界面与样式定制**：
  - 提供独立设置弹窗（默认尺寸 960×740，支持 `Ctrl+Shift+D` 快捷键开启）；
  - 常驻可拖拽悬浮球（FAB），支持边缘智能吸附与 6 款绘图主题图标切换；
  - 图片显示参数可调：最大显示高度（默认 480px）、最大宽度百分比、填充模式与居中对齐；
  - 提供深色、浅色及多套内置色彩主题。

- **受控扩展系统**：
  - 内置插件扩展管理中心，支持在不修改主项目代码的前提下通过标准接口接入自定义逻辑（如画质增强、自定义流水线钩子等）。

## 安装方法

### 方式一：通过 SillyTavern 扩展管理器安装（推荐）

1. 打开并登录 SillyTavern；
2. 点击右上角或设置栏中的 **扩展 (Extensions)** ➔ **扩展管理 (Extension Management)**；
3. 在 **从 URL 安装 (Install Extension)** 文本框中，输入本项目的 Git 仓库地址；
4. 点击 **安装 (Install)** 按钮，安装完成后刷新浏览器页面即可。

### 方式二：手动克隆安装

1. 进入 SillyTavern 的第三方扩展存放目录：
   ```bash
   cd SillyTavern/public/scripts/extensions/third-party/
   ```
2. 执行 Git 克隆命令：
   ```bash
   git clone https://github.com/NoahFoya/ST-DrawAssistant.git
   ```
3. 重启或刷新 SillyTavern 页面。

## 快速上手

### 1. 打开设置面板
- 点击屏幕边沿常驻的悬浮球图标；
- 或使用键盘快捷键：`Ctrl + Shift + D`。

### 2. 配置生图后端
在设置弹窗的左侧导航栏中，选择您正在使用的生图后端：
- **ComfyUI**：输入服务地址（默认 `http://127.0.0.1:8188`），点击“测试连接”，确认正常后选择绘图预设或工作流；
- **SD-WebUI / Forge**：输入服务地址（默认 `http://127.0.0.1:7860`），点击“测试连接”，确认连通后选择模型与采样参数；
- **NovelAI**：输入 API Token 并测试连接；
- **OpenAI 兼容**：输入服务地址、API Key 与模型名称，支持切换不同服务商预设。

### 3. 生成图像
- 在对话中，当 AI 生成回复后，点击消息底部的生图按钮；
- 插件将启动排队与生成，并在按钮上实时显示当前状态或百分比进度；
- 生成完成后，图片将直接呈现在消息下方，点击图片可放大查看原图与生成参数。

## 常见问题排查 (FAQ)

### 1. 为什么连接本地后端时提示网络错误或被阻断？
- **原因**：若您的 SillyTavern 部署在 HTTPS 环境下（例如使用远程域名或反向代理），而生图后端运行在本地 HTTP（如 `http://127.0.0.1:7860`），浏览器会因 **Mixed Content（混合内容）安全策略** 强制拦截请求。
- **解决办法**：在设置面板的 **常规设置 ➔ 请求传输模式** 中，将模式从“直连 (Direct)”切换为 **“宿主中继 (Relay)”**。切换后，请求将由酒馆服务端中转转发，规避浏览器的安全拦截。

### 2. 出图后图片显示过大或过小如何调整？
- 打开设置面板，进入 **常规设置 ➔ 图片显示控制**；
- 可直接修改“最大显示高度”（默认 480px）、“最大显示宽度百分比”以及“对齐方式”，设置将即时应用于所有楼层渲染。

### 3. 如何备份与迁移插件设置？
- 在设置面板的 **关于与生态 ➔ 配置管理与重置** 卡片中，点击 **导出配置** 即可下载包含当前所有参数与预设的 JSON 备份文件；在其他设备上点击 **导入配置** 即可恢复。
