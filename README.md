# ST-DrawAssistant 绘画助手

ST-DrawAssistant 是一款运行于 SillyTavern（酒馆）网页前端的 AI 绘画扩展插件。支持识别对话中的生图指令并在消息楼层内生成与展示图片，对接多种本地与云端生图服务，并提供提示词多通道注入、角色与服装素材管理、本地词库联想、运行统计与本地图库管理。

---

## 运行前提与架构说明

> **重要说明**：ST-DrawAssistant 属于轻量客户端扩展，**插件本身不包含任何生图模型、权重文件或计算引擎**。实际出图依托于在外部独立运行的生图服务（如本地部署的 ComfyUI / SD-WebUI，或云端 NovelAI / OpenAI 兼容 / Google Gemini / xAI Grok 等）。在使用本插件前，请确保对应的生图服务已正常启动并开放了网络访问。

### 推荐通信架构：浏览器直连 (Direct)
插件默认采用**浏览器直连模式**：浏览器直接向生图服务发送 HTTP 请求，具备响应直接、无需经过酒馆服务端转发的优点。

为了让浏览器能够正常访问本地运行的生图服务，需要在外部生图服务的启动配置中允许跨域访问（CORS）：

- **ComfyUI 跨域启动参数（按部署形态设置，改后需重启服务）**：
  - **官方便携包（Windows）**：右键编辑启动脚本（如 `run_nvidia_gpu.bat` / `run_cpu.bat`），在 `main.py` 后追加：
    ```bash
    --listen 127.0.0.1 --enable-cors-header *
    ```
    *(如需同一局域网内手机/平板访问，可将 `127.0.0.1` 替换为 `0.0.0.0`)*
  - **秋叶绘世整合包启动器**：进入启动器「高级选项 / 启动参数」，开启 **允许跨域访问 (CORS)** 或在额外启动参数栏填写 `--enable-cors-header *`（局域网访问同时勾选开放远程连接）；
  - **ComfyUI Desktop（官方桌面版）**：在 Server-Config / 启动参数中附加 `--enable-cors-header *`。

- **Stable Diffusion WebUI / Forge 启动参数**：
  在 `webui-user.bat` 的 `set COMMANDLINE_ARGS=` 中追加：
  ```bash
  --api --cors-allow-origins=*
  ```

### 关于酒馆代理模式 (Proxy) 的使用前提
若你的 SillyTavern 部署在远程 HTTPS 域名下，而外部生图服务运行在本地无 SSL 证书的 HTTP 环境中，浏览器安全策略（Mixed Content）会阻止前端直连。
此时可在「插件设置」中切换为「酒馆代理」模式，由酒馆服务端负责中转 HTTP 请求。请注意：
- **需开启酒馆 CORS 代理配置**：须确保酒馆配置文件 `config.yaml` 中已开启 `enableCorsProxy: true`；
- **适合作为 HTTPS 混合内容或 CORS 受限时的兼容模式**：只要网络与证书条件允许，建议优先使用浏览器直连模式以获得更低的请求延迟。

## 主要功能

### 1. 对话楼层内生图交互
- **生图指令解析与楼层渲染**：当 AI 角色在回复中输出生图指令标记（默认起止标记为 `image###` 与 `###`，示例片段如 `image###正向提示词|负向提示词###`，支持在「插件设置」中自定义起止标记）时，插件会自动解析并将指令替换为消息楼层内的出图容器与图片，不破坏原有对话排版。
- **状态流转、全屏预览与跨应用分享**：出图按钮根据生成状态平滑更新（「点击生图」➔「排队中」➔「生成中」➔「重新生成」）。出图后支持点击图片进入全屏预览（支持滚轮或按钮缩放、双击复原与水平轻扫切图），右键或长按可唤起图像操作面板；楼层图片、全屏预览与「本地图库」卡片均支持一键复制图片至剪贴板，以及直接拖拽图片文件分享至外部应用。
- **提示词微调与局部重绘**：在图像操作面板中可查看该图片的生成参数，基于原始生图提示词微调正向与负向提示词重新出图（不会重复叠加预设前后缀），亦可在支持重绘的本地服务（ComfyUI、SD-WebUI / Forge）下通过辅助画板涂抹选区进行局部重绘 (Inpaint)。

### 2. 生图服务适配
- **ComfyUI**：
  - 支持 API 格式工作流解析与自动填参，出图失败时自动解析展示服务端节点报错明细；任务取消或超时仅中止本地等待，不打断服务端既有任务队列；
  - **工作流基本知识与 API 格式要求**：ComfyUI 通过节点连线控制出图，插件会自动把提示词、主模型、CLIP、VAE、宽高、步数、CFG 与种子填入工作流执行。导入自用工作流时须使用 **API 格式 JSON**：新版 ComfyUI 菜单点 **`工作流 (Workflow) → 导出 (API) / Export (API)`**，旧版网页需先在设置开启「Enable Dev mode Options」再点 **「Save (API Format)」**（普通保存带网页坐标的 JSON 无法直接运行）；导入后点击「格式化变量」一键映射参数，或点「打开蓝图」可视化查看与调整；
  - **内置 4 套开箱即用工作流**：提供「默认 Checkpoint 模型文生图 (原生)」（默认项）、「默认 UNet 模型文生图 (原生)」、「默认 Checkpoint 模型文生图 (WeiLin)」与「默认 UNet 模型文生图 (WeiLin)」。常规单文件底模（`models/checkpoints/`）选 Checkpoint 版即可，CLIP/VAE 保持内置；Flux / SD3 / Qwen-Image / MOSS / Anima 等分立模型（`models/diffusion_models/` 或 `unet/`）选 UNet 版并须在「模型配置」指定 `CLIP 模型` 与 `VAE 模型`（不同架构可进「打开蓝图」切换加载器类型），提交前会自动拦截空项防止服务端报错；原生版零插件依赖，WeiLin 版支持靠 `<wlr:...>` / `<lora:...>` 动态加载 LoRA（需安装 `ComfyUI-WeiLin` 插件），提示条支持勾选不再显示。
- **Stable Diffusion WebUI / Forge**：
  - 支持文生图 (`txt2img`) 与局部重绘 (`img2img`) 接口，自动采纳重绘画板实际宽高并适配 `Automatic` VAE；
  - 支持高分辨率修复 (Hires.fix)、采样器/调度器自动同步及 `<lora:name:weight>` 提示词嵌入转换；取消任务时同样仅中止本地网络等待。
- **NovelAI**：
  - 支持 V3（扁平参数）与 V4、V4.5、V5（结构化 `v4_prompt`）提示词格式，默认将括号权重自动转换为 V4 / V4.5 / V5 原生 `weight::tag::` 数值语法（选用 V3 时自动切换为花/方括号兼容格式），默认采样采用官方推荐的 `k_euler_ancestral` + `karras`（并在「采样与步数」开放调度器切换），按模型族自动匹配禁用服务端内置负向的 `ucPreset` 参数（V3 为 `3`，V4+ 为 `4`），内置预设对齐 V4.5 Full / Curated 质量后缀与 Heavy / Light / Human Focus 负向提示词；支持 ZIP 响应解包（同时兼容第三方中转返回的 JSON 与图像直出流）并自动对齐分辨率；
  - 内置官方模型清单与 5 组 NovelAI V4.5 画师组合预设（柔和日系平涂、清透日系插画、冷色调写实厚涂、柔润二次元插画、水光肌厚涂），支持自定义模型覆写，不向官方或自定义代理发起无效的模型列表拉取。
- **OpenAI 兼容**：
  - 支持标准 `/v1/images/generations` 协议接口及多服务商隔离配置，适配官方 OpenAI（支持 DALL-E 3 画质/风格与 GPT-Image 画质、透明背景、输出格式参数）、SiliconFlow 及自定义兼容服务，自动隐藏不适用的负向提示词与局部重绘入口。
- **Google Gemini**：
  - 对接 Gemini 原生图像生成接口，支持官方服务或自定义中转地址配置，内置 `gemini-2.5-flash-image`、`gemini-nano-banana-2.1`、`gemini-3-pro-image-preview` 与 `gemini-3.1-flash-image-preview`，提供原生画幅比例与按模型能力自动显隐的分辨率档位选择（`512px` / `1K` / `2K` / `4K`），支持自定义请求参数 (JSON) 与从服务端拉取可用的图像生成模型列表（含 `nano-banana` 系列）。
- **xAI Grok**：
  - 对接 xAI 原生图像生成接口（`/v1/images/generations`，适配器层面亦兼容 `/v1/images/edits` 底图编辑请求），内置 `grok-imagine-image`、`grok-imagine-image-2.0`、`grok-imagine-image-pro` 与 `grok-2-image-1212` 等模型，支持按模型能力适配原生画幅比例与 `1K` / `2K` 分辨率档位，支持自定义请求参数 (JSON) 与拉取服务端图像模型列表。

### 3. 提示词注入、预设管理与素材管理
- **提示词多通道注入与预设轮询**：提供故事插画（默认开启，内置标准标签、NovelAI V4.5、英文自然语言与「中文自然语义 (MOSS / 通用)」四套故事插画预设）、词汇指导、素材创作与素材注入四大分类通道；共享同一套触发、深度与变量注入机制，既可按内置模板自由调整或合并，也可在挂载外部绘画世界书时按需前往「提示词 → 启用设置」关闭。生图预设支持绑定固定提示词预设或切换为「使用轮询」模式，可通过独立弹窗管理候选池并自由启用或停用多项预设，在生图与重试时自动轮换抽取；在 ComfyUI 与 SD-WebUI 提示词预设的 LoRA 管理器中，支持为每个 LoRA 单独设定「常驻」或「关键词」触发模式（支持 `|` / 逗号分隔多关键词及 `/正则/i` 语法）。各类预设工具栏统一提供「新建 / 另存为」与「批量导出」，并支持多选 JSON 或合集文件一次批量导入。
- **酒馆原生全局正则持久化与历史清洗**：在「插件设置 → 交互与触发」中提供「绘图与设计思考」显示控制（显示 / 折叠 / 隐藏），以及「清理历史绘图与设计思考」和「清理历史生图与档案标记」两个独立开关，直接幂等同步写入酒馆原生全局正则库，即使插件禁用后依然持久生效。
- **素材管理与简写宏**：在「素材管理」集中维护角色与服装的常驻特征、触发词及各标准部位状态（如 `$爱丽丝-cowboy-clothed$`、`$爱丽丝-closeup-exposed$` 或 `$学院制服-full-intact$`），在提交生图前自动展开为对应标签，避免手动重复编写。
- **提示词清洗与规范化**：自动剔除大模型思考过程标签（`<think>...</think>`、`<imagethink>...</imagethink>`、`<designthink>...</designthink>`）与代码块；默认开启「提示词自动去重整理」对预设前后缀与触发词执行保序 Tag 级去重，同时「中文标点转英文逗号」默认关闭以原样保留 MOSS、Qwen-Image、Gemini、GPT-Image 等模型输出的原生中文标点与自然语义句式（如需兼容旧标签模型误输出中文逗号可按需开启）。

### 4. 本地词库、运行统计与本地图库
- **按需词库分片与输入联想**：内置 10 组按需载入的 Danbooru 本地词库分片（整理去重共 150,658 条标签，默认未载入、不占用初始本地存储空间），支持在「词库 → 词汇文件」单条载入/卸载、启用/停用或点击顶部「一键载入 / 一键卸载」；同时支持导入 Tagcomplete CSV / 双列 CSV / TSV / JSON 词表及「自定义词汇」表格编辑，在编辑提示词时提供多义词排序优化的实时前缀联想补全。
- **运行统计与日志**：在「日志与统计」页汇总累计生成数、今日出图量、近 7 日出图走势双轨微图表（出图数量柱状 + 平均耗时折线）、本地图库容量与最近生成记录。
- **本地存储与本地图库**：生成的图片与生成参数默认保存在浏览器本地存储空间，支持防窥模糊（可在「插件设置」开启）、关键词搜索、服务筛选、收藏过滤、时间排序、图片拖拽分享与复制，以及批量「导出元数据 (JSON)」；仅在酒馆聊天记录中保存轻量图像索引，不会膨胀聊天存档体积。

### 5. 主题设置、悬浮球与本地预设管理
- **阅读向多主题预设**：内置 8 套暗色与亮色主题预设（默认选用护眼的 `Catppuccin Mocha · 柔紫灰`，另含 `Gruvbox Dark · 暖棕琥珀`、`Tokyo Night · 蓝紫夜`、`Nord · 极地灰蓝`、`Rosé Pine Dawn · 暖纸米白` 等），并支持实时微调重点色、背景层级、边框与文字配色及导入导出主题预设。
- **悬浮球外观、绘图动效与快捷面板**：可自由开关常驻悬浮球、调节不透明度与重置停靠位置，切换预设矢量图标或上传本地图片作为圆形头像，并配置生图任务执行期间的悬浮球状态动效（星光环绕 / 流光环绕 / 呼吸脉冲 / 波纹扩散 / 禁用）；支持可选开启「启用快捷面板」（默认关闭），通过桌面端悬停或移动端长按呼出包含「插件设置 / 服务设置 / 提示词 / 素材管理」四个分页的快捷表单面板（含「服务设置」画幅比例与采样参数步进调节）。全界面数值参数统一采用可按键步进与直接输入精确数值的步进输入框；局部重绘画板支持画布缩放平移、撤销重做与空蒙版拦截。
- **版本更新检查与本地预设按需管理**：打开设置面板时自动静默检查更新并在顶栏版本胶囊提示可更新状态，版本升级后首次打开设置自动呈现更新说明；「关于」页内置「本地预设管理」卡片（更新弹窗底部亦可点击「前往预设管理」跳转），按 5 大分类折叠展示全部内置预设，支持单条「载入 / 卸载」、分类「载入本类 / 卸载本类」及全局「全部载入 / 全部卸载」（卸载仅移除对应内置条目，完整保留用户自建及改名预设）。

## 安装方法

通过 SillyTavern 扩展管理器安装：
1. 登录并打开 SillyTavern 网页；
2. 打开顶栏或侧边栏的 **扩展 (Extensions)** ➔ **扩展管理 (Extension Management)**；
3. 在 **从 URL 安装 (Install Extension)** 输入框中粘贴本项目的 Git 仓库链接：
   ```text
   https://github.com/NoahFoya/ST-DrawAssistant.git
   ```
4. 点击 **安装 (Install)**，安装完成后刷新网页即可开始使用。

## 快速配置流程

1. **唤出设置面板与分场景引导**：点击页面右侧常驻的悬浮球图标或扩展面板入口即可打开设置面板。初次打开「插件设置」、首次切换至任意「生图服务」页面或首次进入「提示词 / 素材管理」页面时，将自动弹出对应板块的分场景新手引导；后续也可随时点击设置顶栏右上角的 `?` 帮助按钮定位重看或切换查阅其他部分。
2. **选择生图服务**：点击侧边栏当前激活服务（或在「插件设置 → 基础配置 → 生图服务」中切换当前启用服务，如 ComfyUI 或 SD-WebUI）即可进入对应配置页，点击服务抽屉箭头可展开切换其余服务端。
3. **填写服务地址**：
   - 本地 ComfyUI 默认地址通常为 `http://127.0.0.1:8188`；
   - 本地 SD-WebUI 默认地址通常为 `http://127.0.0.1:7860`。
4. **测试连接与资产同步**：支持资产拉取的生图服务（ComfyUI / SD-WebUI 会拉取模型、采样器、调度器、VAE 与 LoRA；OpenAI 兼容、Google Gemini 与 xAI Grok 会尝试拉取可用图像模型列表且不支持 LoRA，未提供查询接口的中转站可直接手填模型名）请点击卡片右上角「测试连接/同步模型」按钮；NovelAI 仅提供「测试连接」按钮，直接使用内置官方模型清单或自定义模型名覆盖。
5. **配置提示词预设**：在「提示词」选项卡中参照内置起始预设按需调整内容与开关（若已使用外部绘画世界书，亦可关闭内置提示词通道），完成基础设置。

## 常见排障与注意项 (FAQ)

### 1. 点击「测试连接」提示网络错误或无法连通？
- **排查一：外部生图服务是否已启动**：请确认本地服务终端窗口处于运行状态，在浏览器直接打开 `http://127.0.0.1:8188`（ComfyUI）或 `http://127.0.0.1:7860`（SD-WebUI）能够正常看到网页。
- **排查二：是否已添加跨域参数**：ComfyUI 必须配置 `--enable-cors-header *`，SD-WebUI 必须配置 `--cors-allow-origins=*`。若未配置，浏览器控制台会报出 CORS 跨源拦截错误。
- **排查三：SD-WebUI 是否开启了 API 接口**：SD-WebUI 启动参数必须包含 `--api`，否则其后台接口默认不开放。
- **排查四：协议混合拦截**：若酒馆使用 HTTPS 域名，浏览器无法直接请求本地 HTTP 接口，需将酒馆切换为本地 HTTP 运行，或在「插件设置」中权衡开启「酒馆代理」。

### 2. ComfyUI 提示工作流无法执行或缺少节点？
- 确认导入的 JSON 文件是 **API 格式**：新版 ComfyUI 通过菜单 **「工作流 (Workflow) → 导出 (API) / Export (API)」** 导出，旧版需在设置开启「Enable Dev mode Options」后点击 **「Save (API Format)」**；普通「Save」导出的界面工作流无法被后台执行接口识别。导入后可点「格式化变量」自动映射 `%prompt%` 等占位符。
- 若使用 UNet 工作流，须在「ComfyUI → 模型配置」同时选定有效的 `CLIP 模型` 与 `VAE 模型`（Flux / SD3 / Qwen / MOSS 等架构可在「打开蓝图」中调整加载器类型）；若使用 WeiLin 工作流动态加载 LoRA，请确保 ComfyUI 服务端已安装 `ComfyUI-WeiLin` 插件。

### 3. 如何备份已配置的参数或恢复初始状态？
- **配置导出与导入**：在「关于」页中的「配置备份与恢复」区域，点击「导出完整配置 (JSON)」可保存当前所有自定义配置与预设；换设备或重装时点击「导入配置备份 (JSON)」即可恢复。
- **恢复出厂设置**：点击「恢复出厂设置」按钮将打开分类勾选弹窗，可针对性重置全局配置或各类预设方案，本地收藏图库与自定义词库默认隔离保护。
