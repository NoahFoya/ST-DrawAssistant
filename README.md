# ST-DrawAssistant 绘画助手

ST-DrawAssistant 是一款运行于 SillyTavern Web 端的纯客户端 AI 绘画扩展插件，基于 TypeScript 与 Preact 构建。用于在聊天楼层内识别生图指令并生成图片，同时提供多后端服务适配、上下文提示词注入、角色与服装素材档案、本地联想词库、本地图库及主题与悬浮交互定制。

> **架构前提**：本插件**不包含**任何生图模型、权重文件或计算引擎，实际图像生成均依赖外部独立运行的本地或云端生图服务。使用前需预先部署本地服务或准备对应云端服务的 API 凭据。

---

## 核心能力概览

| 能力域 | 核心功能 |
| :--- | :--- |
| **楼层交互与重绘** | 对话指令自动提取与消息内生图、全屏灯箱预览与同位置历史对比、双栏图像编辑工作台、局部重绘画板、浏览器原生图片拖拽 |
| **多生图后端** | ComfyUI、SD-WebUI / Forge、NovelAI、OpenAI 兼容、Google Gemini、xAI Grok，支持浏览器直连与酒馆代理两种传输方式 |
| **提示词与素材** | 四通道提示词注入与酒馆世界书双向转换、酒馆全局正则同步、角色 16 部位/服装 10 部位档案与三段式简写宏、预设轮询与 LoRA 触发 |
| **词库与存储** | 按需载入 10 组 Danbooru 本地词库分片与自定义词表联想、IndexedDB 分表图库、6 档存储格式与绘图参数写入、可选服务端同步转存 |
| **界面与维护** | 多套暗/亮色主题预设与配色自定义、可拖拽悬浮球与四分页快捷面板、运行统计与实时日志、整包配置备份及内置预设按需载入/卸载 |

## 安装与基础接入

### 运行前提
- **SillyTavern 版本**：`>= 1.12.0`
- **外部生图服务**：已启动的本地服务（如 ComfyUI / SD-WebUI）或可用的云端 API 服务（NovelAI / OpenAI 兼容 / Google Gemini / xAI Grok）

### 通过 SillyTavern 安装
仓库已包含预编译构建文件（`dist/index.js`），**通过扩展管理器安装即可直接使用，无需本地编译环境**。

1. 打开 SillyTavern 网页，进入 **扩展 (Extensions)** -> **扩展管理 (Extension Management)**；
2. 在 **从 URL 安装 (Install Extension)** 中粘贴本仓库地址：
   ```text
   https://github.com/NoahFoya/ST-DrawAssistant.git
   ```
3. 点击 **安装 (Install)**，完成后刷新网页即可启用。

### 基础配置路径
1. **打开设置**：点击页面可拖拽悬浮球或扩展菜单入口打开设置面板；首次访问「插件设置 / 生图服务 / 提示词」时会弹出对应使用引导，也可随时点击顶栏 `?` 重看。
2. **连接生图服务**：在设置中选定目标生图服务并填入服务地址或 API 密钥，点击测试连接（本地与部分云端接口可同步拉取模型与资产列表）。
3. **配置提示词通道**：插件默认仅开启「故事插画」注入通道；若已在酒馆挂载外部绘画世界书，可按需关闭内置提示词通道，插件仍会正常识别消息中的生图指令。
4. **触发出图**：发送对话后在消息楼层点击生图按钮，或在「插件设置」开启 AI 回复后自动出图。

### 连接方式说明（浏览器直连 / 酒馆代理）

| 模式 | 适用场景 | 说明与约束 |
| :--- | :--- | :--- |
| **浏览器直连（默认）** | 本地服务（已开启跨域）或支持跨域的云端服务 | 浏览器直接向目标地址发送请求，响应直接且无服务端中转限制。 |
| **酒馆代理（中转）** | 远程 HTTPS 部署的 SillyTavern 访问无证书本地 HTTP 服务 | 经由 SillyTavern `/proxy/` 接口转发 HTTP 请求以规避浏览器混合内容拦截。需酒馆开启代理配置；**TauriTavern 宿主**与 **ComfyUI 局部重绘**均仅支持浏览器直连模式。 |

## 主要功能说明

### 1. 对话楼层交互与图像编辑
- **指令解析与状态同步**：按可自定义的起止标记（默认 `image###...###`，支持通过首个顶层 `|` 拆分正向与负向提示词）提取 AI 回复中的生图指令，支持内部多行与分块描述，自动忽略行内代码、围栏代码块及思考过程标签。按钮实时展示排队与生成状态，删除、编辑消息或切换分支（Swipe）时自动校准队列与图片容器位置，并支持在切换会话或重新生成候选回复（重 roll）时取消旧分支在途任务。
- **三态显示与灯箱预览**：楼层图片支持「正常 / 模糊 / 折叠」三种显示模式，可配置对齐、缩放、最大宽高与圆角。点击图片可进入全屏灯箱缩放平移、切换同位置历次重绘结果进行对比或设为当前展示图；常态下楼层图片、未放大灯箱大图及图库卡片均保留浏览器原生拖拽与快捷复制能力。
- **双栏图像编辑与局部重绘**：支持从楼层图片、灯箱、图库卡片或元信息弹窗呼出图像编辑工作台，微调正负向提示词并切换「复现原参数 / 按当前配置」及固定或随机种子重新生成；从本地图库入口重绘的结果将独立保存至图库而不覆盖原聊天楼层，重绘过程不重复叠加服务预设前后缀。对支持局部重绘的服务可开启双层蒙版画板进行涂抹选区，支持画布缩放平移、撤销重做以及重绘幅度与蒙版边缘模糊调节。

### 2. 生图引擎适配

| 引擎 | 服务接入与模型目录 | 负向词 | 局部重绘 | 核心机制与参数特性 |
| :--- | :--- | :---: | :---: | :--- |
| **ComfyUI** | 本地地址，从 `/object_info` 同步 Checkpoint、UNet、CLIP、VAE、LoRA、采样器与调度器 | 支持 | 支持 | 仅执行 API 格式工作流；内置 Checkpoint 与 UNet 两套原生工作流并自动串联兼容节点加载 LoRA；提供变量映射、节点蓝图预览与服务端节点报错定位 |
| **SD-WebUI / Forge** | 本地地址，拉取底模、VAE、LoRA、采样器与调度器 | 支持 | 支持 | 接入 `txt2img` 与 `img2img`；支持高分辨率修复 (Hires.fix)、CLIP 跳过层数与 `<lora:...>` 自动注入 |
| **NovelAI** | 内置官方地址与自定义反代档位；使用静态模型列表与自定义模型覆写，不拉取远端模型表 | 支持 | 不支持 | 自动区分 V3（扁平参数、SMEA、Decrisper、括号权重）与 V4 / V4.5 / V5（`v4_prompt` 与 `weight::tag::` 数值权重）；按 64 像素取整分辨率，兼容 ZIP、JSON 与图像直出响应；自动禁用内置预设干扰词 (`ucPreset`) |
| **OpenAI 兼容** | 官方、SiliconFlow 与自定义档位；尝试拉取模型列表或手动填写模型标识 | 不支持 | 不支持 | 按模型标识自适应参数（DALL-E 3 画质/风格、GPT Image 画质/透明背景/输出格式/`auto` 尺寸、非硅基兼容端自适应尺寸）；支持自定义请求参数 JSON |
| **Google Gemini** | 官方地址与自定义中转档位；拉取支持 `generateContent` 的图像模型列表（不含 `imagen-*`）或手填 | 不支持 | 不支持 | 按模型能力自适应显示画幅比例（含由模型决定）与分辨率档位；重绘传入底图时附带为参考图；支持自定义请求参数 JSON |
| **xAI Grok** | 官方地址与自定义中转档位；拉取 Grok 图像模型列表或手填 | 不支持 | 不支持 | 按模型能力控制 `grok-imagine-image` 与 `grok-2-image` 的原生画幅比例（含由模型决定）与分辨率档位；重绘携带底图时路由至编辑接口；支持自定义请求参数 JSON |

> **补充说明**：
> - ComfyUI 与 SD-WebUI 取消任务或触发超时时仅中止客户端请求与轮询等待，不向服务端发送全局打断指令；
> - ComfyUI 内置自动 LoRA 注入会对 `.gguf` LoRA 或 Nunchaku 等不兼容量化节点工作流给出拦截提示；导入含 `WeiLinPromptUI` 节点的自定义工作流时将自动改用 `<wlr:...>` 触发词语法。

### 3. 提示词注入、素材与词库分工

插件将「发送给对话模型的注入文本」「提交给生图引擎的出图提示词」与「界面编辑框输入联想词库」分离为三条独立通道：

| 模块 | 作用方向与对象 | 核心机制与能力范围 |
| :--- | :--- | :--- |
| **上下文注入（提示词页）** | 上行（随对话发往大语言模型） | 提供「故事插画」（默认开启，含标签与自然语言预设）、「词汇指导」、「素材创作」与「素材注入」四通道；每条规则支持常驻或关键词/正则触发及扫描深度设置，支持与 SillyTavern 世界书 JSON 双向导入导出。内置故事插画仅负责情节与构图引导、默认不输出画质词，固定画风统一配置在对应生图服务底部。 |
| **全局正则持久化（插件设置）** | 作用于酒馆前端展示与历史上下文 | 提供「绘图与设计思考」展示模式（显示 / 折叠 / 隐藏）及「清理历史绘图与设计思考」「清理历史生图与档案标记」开关，规则同步写入酒馆原生全局正则库，停用本插件后仍在酒馆中保持生效。 |
| **出图预处理（生图提交阶段）** | 下行（发往外部生图引擎前） | 提取生图指令并剥离思考块与代码块，展开 `$名称-宏-状态$` 与 `($名称-宏-状态$)` 三段式简写宏；按当前服务配置合并固定画风预设或从轮询池随机抽取的风格预设，并挂载常驻或关键词触发的 LoRA；随后按开关执行英文标签保序去重、标点空行整理、可选中文标点转换及 NovelAI 权重转换。 |
| **素材管理** | 维护角色与服装词条供宏展开及注入 | 按角色 16 项身体部位（支持 `covered` / `exposed` / `nude` 分层状态，不含衣物）与服装 10 项穿戴部位（支持 `intact` / `disheveled` 分层状态）管理词条与参考图；支持按酒馆角色卡名称搜索绑定自动切换启用清单，并在识别到对话中的新档案时弹窗供新建、覆盖或按空缺部位合并。 |
| **本地词库** | 纯本地输入框手动编辑辅助 | 内置 10 组按需载入的 Danbooru 词库分片（默认未载入、不占用初始本地存储），同时支持导入常见 CSV / TSV / TXT / JSON 词表及维护自定义词条表。输入提示词时仅对光标左侧当前片段执行联想与 `$...$` 宏补全，**不会发送给大模型**。 |

### 4. 存储管理、日志统计与外观定制
- **本地图库与元数据写入**：生成的图像及参数默认保存在浏览器 IndexedDB（元数据与二进制分表存储），聊天记录仅留存轻量索引；支持 6 档存储格式（`原图`、`无损 PNG` 以及多档 `WebP` / `JPEG`），自动保留原有 PNG 参数块并在缺参图像上补写 ComfyUI 或 A1111 参数，下载时按真实图像格式匹配文件后缀，亦可开启同步上传至 SillyTavern 服务端目录。图库支持关键词搜索、按服务筛选、收藏过滤、批量导出元数据 JSON 及批量删除。
- **日志与统计**：提供累计及今日出图统计、近 7 日出图量与平均耗时复合图表、本地存储占用视图（支持按失败记录 / 未收藏 / 全量清理）及实时日志终端。
- **界面定制与快捷入口**：内置多套暗色与亮色主题预设，支持配色参数自定义与导入导出；提供可拖拽悬浮球、自定义圆形头像与绘图状态动效，并可选开启悬浮球四分页快捷面板直接调节常用开关与生图参数。
- **配置维护与版本检查**：支持预设合集批量导入导出；在「关于」页按五大分类按需载入或卸载内置预设（不影响个人自建与改名条目）；支持整包配置导出备份与分类恢复出厂设置（默认隔离保护图库与自定义词库）；集成三级在线更新检查（优先宿主 Git 仓库比对，回退远程提交或 `manifest.json` 语义版本比对）、宿主一键更新及问题诊断报告复制。

## 连接配置与常见排障

### 1. 本地生图服务跨域参数（CORS）
浏览器直连模式下，本地生图服务需在启动参数中允许跨域请求（调整后须重启服务）：
- **ComfyUI**：
  - 官方 Windows 便携包（编辑 `run_nvidia_gpu.bat` 或 `run_cpu.bat`，在 `main.py` 后追加）：
    ```bash
    --listen 127.0.0.1 --enable-cors-header *
    ```
    *(同一局域网下跨设备访问可将 `127.0.0.1` 替换为 `0.0.0.0`)*
  - 秋叶绘世整合包启动器：在高级选项中开启允许跨域访问，或在额外参数填入 `--enable-cors-header *`
  - ComfyUI Desktop（官方桌面版）：在 Server-Config / 启动参数中附加 `--enable-cors-header *`
- **SD-WebUI / Forge**（在 `webui-user.bat` 的 `set COMMANDLINE_ARGS=` 后追加）：
  ```bash
  --api --cors-allow-origins=*
  ```

### 2. 使用「酒馆代理」模式的前置配置
当 SillyTavern 运行于 HTTPS 域名且需连接本地无 SSL 证书的 HTTP 服务时，可在切换为「酒馆代理」前确认服务端 `config.yaml` 配置：
- 开启 CORS 代理开关：`enableCorsProxy: true`（或启动酒馆时携带 `--corsProxy` 参数）；
- 若开启了 SSRF 私网拦截且代理目标为本机 (`127.0.0.1`) 或局域网地址，需在 `privateAddressWhitelist.allowedRanges` 中放行对应 IP 范围；
- 注意：TauriTavern 外壳未提供 `/proxy/` 接口，且 ComfyUI 局部重绘需以 `multipart/form-data` 上传文件，上述两项场景需使用「浏览器直连」。

### 3. ComfyUI 工作流格式与模型加载提示
- 导入自定义工作流须使用 **API 格式 JSON**：新版 ComfyUI 通过 **`工作流 (Workflow) -> 导出 (API) / Export (API)`** 获取，旧版需在设置开启 `Enable Dev mode Options` 后使用 **`Save (API Format)`**（普通保存的界面图 JSON 无法直接运行）。
- 使用内置「默认 UNet 模型文生图 (原生)」处理分立模型时，需同时在模型配置中指定匹配的 `CLIP 模型` 与 `VAE 模型`（不同模型架构可通过蓝图功能调整加载器类型）。
- 使用包含 `WeiLinPromptUI` 节点的自定义工作流时，请确认 ComfyUI 服务端已安装 `ComfyUI-WeiLin` 扩展。

## 项目结构与本地开发

> 本节仅面向二次开发与构建维护人员。**通过 SillyTavern 安装使用的用户无需进行本节操作**。

### 目录结构（受 Git 跟踪源码与资产）

```text
ST-DrawAssistant/
├── manifest.json          # SillyTavern 扩展清单与生命周期钩子定义
├── package.json           # 依赖与构建脚本声明
├── tsconfig.json          # TypeScript 编译配置
├── webpack.config.js      # Webpack 打包配置
├── @types/                # SillyTavern 宿主与多生图引擎 TypeScript 类型声明
├── config/                # 出厂默认配置、更新日志 (changelog.json)、内置预设与分片词库
├── styles/                # 样式令牌、通用控件、功能视图样式与响应式规则（入口 main.css）
├── dist/                  # 生产打包输出文件 (dist/index.js)
└── src/                   # 源码目录（按自上而下单向分层组织）
    ├── index.ts           # 扩展入口与激活/卸载生命周期
    ├── config/            # 全局常量定义
    ├── domain/            # 无宿主依赖的纯业务规则、正则触发、宏与后端能力规格
    ├── host/              # SillyTavern 宿主上下文、API 与事件桥接适配层
    ├── util/              # 事件总线、HTTP 传输与重试、图像压缩/元数据与存储端口
    ├── store/             # 设置仓库、凭据本地隔离、预设生命周期与 IndexedDB 存储
    ├── provider/          # 6 大生图后端适配器、ComfyUI 节点注入与注册中心
    ├── pipeline/          # 提示词注入、下行预处理、宏展开、档案提取、任务队列与更新服务
    └── ui/                # 入口控件、声明式框架、无 DOM 状态层、设置视图、媒体编辑与主题服务
```

模块依赖保持自上而下约束：`entry (src/index.ts) -> ui -> pipeline -> provider / store -> host / util -> domain`。

### 本地开发命令

```bash
npm install          # 安装构建依赖
npm run type-check   # 运行 TypeScript 类型检查 (tsc --noEmit)
npm run dev          # 启动 Webpack 开发监听构建
npm run build:dev    # 执行一次开发模式构建
npm run build        # 生成生产环境打包文件 dist/index.js
```
